# 卡關排除（安裝和裝好之後）

先跑 `node tool.mjs status`，看 `recent_errors`、`last_run`、`LINE.本月推播`。說是「環境問題」之前先跑一個能證明的檢查。

| 症狀 | 先查 | 怎麼修 |
|---|---|---|
| `check` 說 Cloudflare 沒登入／續期失敗 | — | `open 登入Cloudflare.command`，他在網頁按 Allow |
| `init` 子網域建不起來 | Cloudflare 網頁 → Workers & Pages | 請他在網頁上幫 workers.dev 取一個名字，再跑一次 `init` |
| `deploy` 說排程（cron）超過上限 | 免費帳號整個帳號最多 5 個排程 | 這套只用 1 個；看帳號裡別的 Worker 是不是用光了 |
| `secret` 說剪貼簿裡不是 secret | — | 請他在 LINE Developers → Basic settings 的 Channel secret 旁按複製圖示，再跑一次 |
| `webhook` 失敗 401／bad signature | secret 錯了 | 重跑 `secret`；剛 deploy 完的話等 30 秒再跑 `webhook` |
| `webhook` 失敗 LINE token 錯誤 | Channel ID 填錯、或 secret 被重發過 | 重跑 `channel <ID>` → `deploy` → `secret` |
| LINE 講話機器人沒回 | `status`：`owner_bound`、`webhook.active`、`chatMode` | 第 7 關回應設定再看一次（聊天要關、Webhook 要開）；`webhook` 再跑一次 |
| 回「這是○○私人的帳號」 | 第一個傳話的人會被綁成主人 | 綁錯人：`node tool.mjs sql "DELETE FROM kv WHERE k='owner'"`，再請他本人傳一句 |
| 回「原話先存進記事本了，不過 AI 有點狀況」 | `recent_errors` | Workers AI 每日免費額度用完（隔天恢復）或模型下架：`worker.js` 的 `LLM_MODELS` 換成 Cloudflare 現有的模型 → `deploy` |
| 語音一直聽錯某個字 | — | 請他在 LINE 說「剛剛的 X 是 Y」（自動記進字典）；或 `node tool.mjs dict add X Y`；常用詞加進 config.json 的 `words` → `deploy` |
| 分類常分錯 | config.json 的 `about`、`desc` | 把那類的 `desc`、`keywords` 寫具體一點 → `deploy`；單筆分錯在 LINE 按「🏷️ 改分類」 |
| 沒收到行程提醒 | `list`：那筆有沒有「已推提醒」；`本月推播` | 講的時候離開始不到 10 分鐘不會提醒；本月用到 185 則會停推提醒（改靠手機行事曆響），下個月 1 號恢復 |
| 早上沒收到摘要 | `last_run` | 寫 ERROR 就看錯誤內容；摘要時間後 30 分鐘系統會自己檢查並通知 |
| 手機行事曆沒出現 | `calendar_installed` 有沒有時間 | 沒有＝沒訂閱成功，請他在 LINE 打「裝行事曆」重來；有＝等 15 分鐘～1 小時同步，iPhone 設定 → 行事曆 → 帳號 → 已訂閱的行事曆 看得到 |
| LINE 本月推播快用完 | `本月推播.totalUsage` | 免費 200 則／月，每天摘要約 30 則，剩下給提醒；回覆他的話不算額度 |

## 改程式前怎麼測（不會真的發 LINE、只動測試資料庫）
```bash
cd <工作資料夾> && PATH="$HOME/.local/node/bin:$PATH" CLOUDFLARE_API_TOKEN=$(node cf-token.mjs) CLOUDFLARE_ACCOUNT_ID=$(node -p 'require("./.setup.json").account') wrangler dev --remote --port 8799 --var TEST_MODE:1
```
另一個指令視窗：
- `curl localhost:8799/test-init`（第一次）
- `curl "localhost:8799/test?q=明天下午三點看牙醫"`：看 AI 怎麼分、回什麼
- `curl "localhost:8799/test-cron?c=remind&at=2026-01-31T14:35"`：假裝現在幾點，看會推什麼
- `curl "localhost:8799/test-cron?c=morning&monday"`：看早上摘要（週一版）
- `curl localhost:8799/test-ics`：看行事曆檔
- 測完關掉：`pkill -f "wrangler dev --remote --port 8799"`
- 他也可以在 LINE 說「測試模式」：講的話只進測試資料庫，2 小時自動關；「清空測試」清掉
