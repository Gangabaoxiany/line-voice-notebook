```markdown
# 〈機器人名字〉｜我的 LINE 語音記事本

**一句話：在 LINE 對「〈機器人名字〉」講話（語音或打字），它先存原話、自動分類、排提醒，同步到手機行事曆；每天 〈早上時間〉 推今日摘要，行程前 〈N〉 分鐘提醒。**

## 怎麼用
| 在 LINE 講 | 它做什麼 |
|---|---|
| 「明天下午兩點跟王大哥開會，在公司」 | 排行程，前 〈N〉 分鐘提醒，進手機行事曆 |
| 「提醒我下午五點打電話給媽媽」 | 待辦，17:00 提醒；講「打給媽媽做完了」就打勾 |
| 「今天去健身房練腿」 | 記事 |
| 一句講好幾件事 | 全部分開記 |

分類：〈icon 分類名、…〉

## 常用指令
| 打或講 | 回什麼 |
|---|---|
| 「這個月」 | LINE 月曆，點日期看那天 |
| 「今天」「明天」「這週」 | 那幾天的清單 |
| 「待辦」 | 還沒做的，按 ✅ 打勾 |
| 「記事本」「昨天記了什麼」 | 那天講過的原話 |
| 「這週回顧」 | 這 7 天照分類列出來 |
| 「查 王大哥」 | 找以前的紀錄 |
| 「剛剛的 X 是 Y」 | 改錯字，以後自動改 |
| 「狀態」「壞了」 | 系統狀態 |

## 手機行事曆
- 〈iPhone：LINE 按「📲 裝到手機行事曆」→ 訂閱／Android：Google 日曆網頁版「透過網址新增」〉，只要一次（〈日期〉 已裝好）

## 免費額度
- LINE 每月 200 則推播（回覆不算）；用到 185 則自動停提醒，改靠手機行事曆響
- Cloudflare 免費方案；資料在我自己的 Cloudflare 帳號

## 壞掉時
1. 在 LINE 打「壞了」看狀態
2. 打開電腦的 Claude，說「**LINE 記事本壞了**」，它會照這份修
3. 講過的原話都先存進記事本了，不會掉

## 給 Claude 看
- 工作資料夾：〈路徑〉；設定 `config.json`；帳號資料 `.setup.json`；工具 `tool.mjs`
- Worker 網址：〈網址〉；LINE Channel ID：〈ID〉；Channel secret 只在 Cloudflare 機密設定
- 改設定：改 config.json → `~/.local/node/bin/node tool.mjs deploy`
```
